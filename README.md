 # RoadAid

  RoadAid is a vehicle emergency assistance web application that helps drivers quickly request roadside support when
  they face unexpected problems on the road.

  ## About the Project

  RoadAid is built to connect users with nearby assistance for common roadside emergencies such as:

  - Tire punctures
  - Fuel shortage
  - Vehicle breakdowns
  - Many More Emergency roadside service requests

  The application is designed to provide a simple flow for requesting help, tracking service progress, and improving
  response time during urgent situations.

  ## Features

  - User authentication
  - Customer and mechanic registration
  - Emergency service request flow
  - Nearby mechanic support
  - Service status tracking
  - Admin management views
  - Responsive web interface

  ## Tech Stack

  - React
  - Vite
  - React Router
  - Axios
  - Django REST backend
  - SQLite database
